# Changelog

本文件记录 ScholarPilot 的用户可见变更。v0.6.0 在全部发布门禁通过前保持
候选版本状态。

## [0.6.0] - Unreleased

### Added

- 请求级 `SearchDeadline`：50 秒总预算、阶段上限、剩余预算、取消状态和阶段耗时。
- 查询分析、OpenAlex、Semantic Scholar、Selector、精排与反事实验证的线程安全
  TTL 缓存。
- 成功、真实空结果、单源降级和结构化错误的 v1.0 JSON Schema。
- `requestId`、`sourceStatus`、`retrievalRoutes`、Token 统计、配置哈希和停止原因。
- 证据质量、来源一致性、证据不足标记和可配置排序权重。
- P@10/20、R@20/50、F1@20、P50/P95、逐查询预测和可复现元数据。
- 20 请求指标隔离、超时、取消、429、真实空结果和单源失败回归测试。
- 当前树、Git 历史和客户端构建物密钥扫描，以及机器可读验收脚本。

### Changed

- 前端代理总超时改为 55 秒，客户端取消信号传播到 Python。
- 初始子查询最多 3 条，总学术 API 预算默认最多 10 次。
- 仅在预算和预期收益允许时进入引文扩展、下一轮检索、精排和反事实验证。
- 429、可重试 5xx 和网络瞬断使用有界重试；等待超出剩余预算时立即停止。
- OpenAlex/Semantic Scholar 成功返回空集合不再被误判为后端失败。
- live 请求开始和失败时清除旧结果，避免 demo 或上一次搜索残留。
- 应用和包版本更新为 `0.6.0`。

### Security

- `.env.example` 只保留空凭据和非敏感默认值。
- 当前跟踪树及 `dist/client` 扫描均为 0 命中。
- 完整 Git 历史仍有 3 条旧提交命中；需要仓库所有者授权后改写历史，并在服务商
  控制台确认旧 Key 已撤销。因此 v0.6.0 不能标记正式发布。

### Known blockers

- 35 条旧评测数据仍有 58 个 warning，尚不能证明 F1 达到 v0.6 门槛。
- staging/production 尚未部署和验收。
- 多实例生产部署需要 Redis 或平台级共享限流。
