# ScholarPilot v0.6 — Reliable Search

状态：**Release Candidate，未正式发布**

v0.6 把 ScholarPilot 从“各步骤尽力完成”升级为“在统一预算内成功，或给出可操作
的结构化失败”。live 搜索不再因某个步骤的独立重试无限挤占总时间，单数据源失败
时可使用另一真实数据源，所有上游失败时明确返回 502，真实空集合则返回
`status=no_results`。

## 用户可见变化

- 页面区分成功、真实空结果、单源降级、超时、第三方限流、用户限流和后端未就绪。
- 每次请求都有 requestId；错误显示失败阶段、是否可重试和建议。
- 论文卡片显示证据质量、来源和检索路线，证据不足会明确标记。
- 新搜索及失败会清除旧结果，不会把 demo 或上一次结果误当作本次 live 输出。

## 工程变化

- Python 总预算 50 秒，前端代理 55 秒；取消信号传播到后端。
- 双源并行召回、最多 3 条初始子查询、最多 10 次 API、预算感知早停和熔断。
- 请求级 Token/API 指标，阶段耗时，配置哈希和可复现评测元数据。
- v1.0 Query Contract、成功响应和错误响应 JSON Schema。
- 44 个 Python 测试、TypeScript/ESLint/生产构建和 3 个渲染/API 测试通过。

## 发布阻塞

- 完整 Git 历史仍命中 3 条旧凭据记录；历史清理需要仓库所有者明确授权。
- 旧 Key 是否已在 DeepSeek/OpenAlex 控制台撤销，需要账户所有者确认。
- 评测数据审计仍有 58 个 warning，demo Macro F1 0.1061 只能用于回归，不能声称
  算法效果提升。
- staging/production URL、真实 live P50/P95 和部署后 20 并发尚未验收。

只有上述阻塞全部解除且完整验收报告为 `passed`，才能把本候选版本标记为正式
v0.6。
