## 解除阻塞的顺序

1. 账户所有者确认旧 Key 已撤销。
2. 仓库所有者授权历史重写、协作者重新克隆和强推窗口。
3. 按标注规范人工核验至少 30 条查询，冻结开发集和保留集。
4. 运行召回/排序消融、两次复现和 live 延迟成本测试。
5. 修复或重建 Sites 项目并提供公网 Python 后端，完成 staging 验收。
6. 全部门禁通过后再发布 production 与正式 v0.6 release。
